Creator Bot Pipeline

A six-agent production system for short-form video. Deterministic handoffs, bounded work, and explicit approval keep the path from footage to publish operationally sound.

Operating principles

01 / OrchestrationCentral coordination, explicit state, observable handoffs.
02 / One instructionKeep each agent's active task narrow and unambiguous.
03 / Sample firstValidate a small slice before committing to full work.
04 / Quota disciplineBound calls, retries, and expensive processing.
05 / Approval gatesRequire owner review before release.

Agents

Maestro

Coordinates the run, enforces sequencing, and keeps state visible across agents.

Glimpse

Finds high-signal moments in raw footage and returns a focused candidate set.

Cut

Turns approved candidates into concise, platform-ready edits.

Drop

Runs quality checks and manages the release queue ahead of approval.

Shop

Supports commerce-oriented context and keeps product work separated from core flow.

Roger

Provides operational support, diagnostics, and reliable follow-through.

Designed for controlled throughput: inspect, edit, verify, approve, publish.
